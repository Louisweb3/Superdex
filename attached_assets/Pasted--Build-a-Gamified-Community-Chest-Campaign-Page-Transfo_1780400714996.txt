# Build a Gamified Community Chest Campaign Page

Transform the current "Earn" page into a premium, highly animated, gamified **Community Campaign** experience that feels like a seasonal Web3 event rather than a traditional rewards page.

## Objective

Create a Community Chest Campaign where users complete social tasks, verify ownership of their wallet, open randomized reward chests, earn XP, invite friends, and compete on a leaderboard.

The experience should feel polished, premium, engaging, and production-ready with smooth animations, modern UI, and real-time XP updates across the application.

# Campaign Flow

## Step 1: Community Verification

Users must complete:

1. Follow official X account
2. Like campaign post
3. Repost campaign post
4. Connect wallet
5. Sign verification message

Verification message example:

"I am participating in the Community Chest Campaign."

No gas fees required.

Show completion status with animated checkmarks.

---

## Step 2: Claim Community Chest

After verification:

Unlock a large CTA button:

"Open Community Chest"

Button should glow and pulse.

When clicked:

### Chest Opening Animation Sequence

1. Darken background
2. Bring chest to center screen
3. Camera zoom effect
4. Chest shakes
5. Energy builds around chest
6. Chest bursts open
7. Particle explosion
8. Reward card reveal
9. XP count-up animation
10. Celebration effects

Use smooth motion and premium game-like transitions.

# XP System

XP is the core progression mechanic.

Create a global XP system.

Every earned XP must:

* Be stored in database
* Be attached to wallet address
* Update instantly across application
* Trigger count-up animation

XP should update in:

* Navbar
* Profile page
* Campaign page
* Leaderboard
* Referral dashboard

Use real-time synchronization.

Suggested implementation:

* WebSockets
* Supabase Realtime
* Live subscriptions

---

# Database Structure

Users Table:

* wallet_address
* total_xp
* campaign_xp
* referral_xp
* rank
* created_at
* updated_at

XP Transactions Table:

* id
* wallet_address
* source
* amount
* reference_id
* created_at

Sources:

* community_chest
* referral_bonus
* campaign_bonus
* manual_reward

Never directly edit total XP.

Always calculate XP from transaction history.

Create transaction records for every XP reward.

# Referral System

Generate referral link automatically:

app.com/ref/{wallet}

Reward:

Referrer earns 25% bonus XP from all XP earned by invited users.

Example:

Friend earns 20,000 XP

Referrer receives 5,000 XP

Bonus XP must be generated separately and not deducted from referred user.

Referral Dashboard:

* Total Invites
* Referral XP Earned
* Top Referrals
* Referral Activity Feed

# Backend Logic

When user opens chest:

1. Verify tasks completed
2. Verify wallet signature
3. Determine reward tier
4. Generate XP reward
5. Create transaction
6. Update total XP
7. Update leaderboard
8. Update referral rewards
9. Broadcast real-time updates
10. Display animation

Prevent abuse:

* One claim per campaign period
* Wallet verification required
* Server-side reward generation
* Anti-bot protections
* Duplicate wallet detection
