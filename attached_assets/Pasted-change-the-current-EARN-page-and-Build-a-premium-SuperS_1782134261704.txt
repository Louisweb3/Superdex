CLAIM PROCESS:

When user clicks "Claim 10,000 XP":

1. Open confirmation modal.
2. Show:

   * Reward: 10,000 XP
   * gas: 0.000040 ETH
   * Network: Base
3. User confirms.
4. Execute contract transaction:

```ts
claim()
value: 0.000040 ETH
```

5. Wait for transaction confirmation.
6. Show loading state with progress animation.
7. After success:

   * Display confetti animation
   * Display chest opening animation

   * Refresh XP balance
   * Mark wallet as claimed
